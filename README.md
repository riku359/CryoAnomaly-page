# CryoAnomaly Project Page

Local static project page for **CryoAnomaly: Few-Shot Cryo-EM Particle Picking via Anomaly-Guided Hard Negative Suppression**.

Open:

- `index.html`

## Assets

Figures were exported from the IEEE Access manuscript (`ieee_access_draft`):

- `assets/teaser.png` — pipeline overview (paper Fig. 2, `main_fig_20260203.pdf`)
- `assets/qualitative_picking.png` — 2D picking comparison w/ vs. w/o anomaly loss (`20260125_qualitatve_result.pdf`)
- `assets/reconstruction_3d.png` — 3D local-resolution maps on EMPIAR-10081 (`3d_reconstruction_comparison.pdf`)

Main Results table = paper **Table 4** (1-shot comparison on five CryoPPP datasets).
